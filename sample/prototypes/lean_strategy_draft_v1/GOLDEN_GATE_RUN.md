# Golden Gate Marketing Plan — Strategy Workflow Run

Prototype route:

```text
/prototype/golden-gate-plan
```

Purpose: test whether the externalized modular Strategy Workflow can produce a useful marketing plan from a rich GTM deck without dumping the plan into CMO chat or Stream.

## Active modules in this run

1. Market Context
2. Buyer Map
3. Strategy Draft
4. StoryBrand Lens
5. Offer Architecture
6. Distribution System
7. Tactical Funnel
8. Measurement Model
9. 30-Day Activation Work Orders

## Disabled / future modules

- AI Sales Concierge automation
- Broker OS automation
- Attribution dashboard automation

These are included as planned capability surfaces only, not functional prototype modules.

## Core strategic output

Golden Gate should own:

```text
Family Legacy Planning for Northern Cebu Families
```

The plan leads with:

```text
“I already handled it.”
```

Not:

```text
cemetery lots for sale
```

## GTM archetype

```text
Local-market emotional urgency + broker distribution + lead magnet conversion
```

## Primary buyer trigger

```text
Aging parents + OFW absence + no existing memorial property
```

## First activation path

```text
Family Memorial Readiness Checklist
→ Memorial Care Fund or site consult
→ lot reservation / family plan
→ testimonial + family referral loop
```

## Why this run has value

It proves the Strategy Workflow can hold:

- market facts
- buyer psychology
- narrative framework
- offer ladder
- broker distribution
- tactical funnel
- measurement model
- work orders

without requiring a single overloaded GTM artifact card.
