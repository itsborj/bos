Demo boundary

Allowed and forbidden outcomes

This keeps the public page useful without creating unnecessary security or product-risk surface area.

Allowed

  • Read exact public URLs provided by the visitor.
  • Accept pasted text, PDF text, brochures, and company profiles.
  • Generate a provisional brand profile with confidence labels.
  • Let public chat correct/enhance the provisional profile only.
  • Generate the full marketing-plan format from available evidence.
  • Email the generated result or capture waitlist consent.

Forbidden

  • No login-wall bypass to BOS workspace data.
  • No public API keys or direct Strategy Workflow endpoint exposure.
  • No social scraping in V1.
  • No ecommerce inventory crawl, sitemap crawl, or hidden page crawling.
  • No connector actions, publishing, spend changes, or external tool execution.
  • No pretending inferred sections are confirmed facts.
