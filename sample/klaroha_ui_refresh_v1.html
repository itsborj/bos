02 — Dark / Light Contrast Principle
✓ Light surface → Racing Green text
Headline on White
Body copy at paragraph size. Racing Green on white passes WCAG AAA at all sizes. No separate muted gray — weight and size create hierarchy.
Tagline or secondary note in italic at reduced opacity — still Racing Green, still passes contrast.
✓ Dark surface → Ivory text
Headline on Obsidian
All text on dark surfaces is Ivory. No Racing Green on Obsidian — fails contrast. Sage (#9cbd77) for sublabels only — never body copy on dark.
Sublabel or secondary note in Sage — dark-only usage.
✓ Ivory card → Racing Green text (same rule, warm surface)
Card heading
Body on Ivory. Same Racing Green — passes contrast on both white and ivory. No special ivory-specific token needed.
Amber — display only

08 — Token Quick Reference
TokenValueUse forNever use for
--racing-green #0b3d2e All text on white/ivory. Headline, wordmark, CTA outline, nav active, structural chrome. Text on dark surfaces. CTA fill.
--coral #ef8250 Primary task CTA fill — Submit, Confirm, Create, Approve, Get started. One per flow. Status, decoration, text, secondary actions.
--amber #fcc167 Tagline italic. Pull-quote. Eyebrow label. Logo clarity dot. Display sizes only. Body text (fails contrast). Status. Navigation.
--highlight #fffe9c Callout fill. Annotation background. Inline emphasis marker. Text color on any surface.
--crimson #de425b Error, failed routing, system alert only. Lightened tint on dark surfaces. Brand use of any kind. Decoration.
--forest #4b7c54 Hover/active tint. Positive delta indicators on light surfaces. Standalone brand color. CTA.
--sage #9cbd77 Sublabels on Obsidian/dark surfaces only. Any use on white or ivory — fails contrast.
--bg / --bg-card #ffffff / #f5f1e8 Default canvas / warm card fill. Text on these = Racing Green. Text or foreground color.
--bg-dark #080b0d Cockpit sections, dashboard, footer. Text on this = Ivory. Default page background.
