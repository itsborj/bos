Appendix

Technical Architecture Overview

The Stack
FastAPI + PostgreSQL backend, React/Vite frontend, deployed via Docker on self-hosted or managed VPS.
Operational Design
• Multi-brand: Clean data isolation for multiple accounts.
• Extensibility: Plugin-based channel capabilities (Gmail, GAds, Meta).
• LLM-Agnostic: Support for OpenAI, Anthropic, OpenRouter.
Control & Trust
• BYOK: Full cost control via customer-owned API keys.
• Audit Trail: Every AI execution is logged with explicit approval gates.
