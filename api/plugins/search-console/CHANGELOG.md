# Search Console Plugin Changelog

## 0.1.0 — Native read-only Search Console plugin

### Added

- Added custom BOS Search Console plugin scaffold.
- Added `marketing.channel.search_console.properties.list`.
- Added `marketing.channel.search_console.performance.query`.
- Added `marketing.channel.search_console.url.inspect`.
- Added `marketing.channel.search_console.sitemaps.read`.
- Added `marketing.channel.search_console.opportunities.plan`.

### Boundaries

- Native Google Search Console APIs only.
- No Membrane, Rube, Composio, or MCP sidecar.
- No Search Console mutations in v1.
- No BOS core/router changes.
