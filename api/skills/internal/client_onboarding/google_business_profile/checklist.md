# Google Business Profile Client Onboarding Checklist

Before sending, confirm:

- Client name is present.
- Google Business Profile access email is present or TODO-flagged.
- Access guide link is present if available.
- Google Drive folder link is present or TODO-flagged.
- Onboarding questionnaire link is present or TODO-flagged.
- Questionnaire source content is available in `questionnaire_template.md` if the client-specific Google Doc has not been created yet.
- Kickoff call scheduling link or time is present or TODO-flagged.
- Creative/resource request includes logos, promotional media, persona info, testimonials, and business photos/video.
- Delivery team contacts are present or TODO-flagged.
- Signoff name is present or TODO-flagged.
