# Competitor Profiles — Org-Level Drop-in

Drop competitor profile markdown files here for org-wide defaults.
These load for any brand that does not have brand-scoped competitor docs
uploaded via Admin → Brand → Documents.

## File format

One file per competitor. Filename: `{competitor_slug}.md`

Suggested sections:
- **Overview** — what they do, positioning, target segment
- **Channels** — where they are active and estimated spend/effort
- **Messaging** — core claims, tone, hooks
- **Strengths** — what they do well
- **Weaknesses** — gaps we can exploit
- **Pricing signals** — public pricing or tier structure if known
- **Recent moves** — campaigns, product launches, partnerships

## Brand-scoped competitor docs (preferred)

Upload via Admin → Brand → Documents with `doc_type=competitor_profile`.
Brand-scoped docs take precedence over files in this folder.
