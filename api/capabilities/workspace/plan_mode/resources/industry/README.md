# Industry Reports — Org-Level Drop-in

Drop industry and market research markdown files here for org-wide defaults.
These load for any brand that does not have brand-scoped industry docs
uploaded via Admin → Brand → Documents.

## File format

One file per report. Filename: `{vertical}_{year}.md` e.g. `saas_marketing_2026.md`

Suggested sections:
- **Market size** — TAM, SAM, SOM if available
- **Growth rate** — YoY trends
- **Key segments** — buyer personas and their characteristics
- **Channel trends** — which channels are growing/declining in the vertical
- **Benchmarks** — CPL, CAC, conversion rates, email open rates by segment
- **Key players** — major competitors and their estimated market share
- **Emerging signals** — regulatory, technology, or behavior shifts

## Brand-scoped industry docs (preferred)

Upload via Admin → Brand → Documents with `doc_type=industry_report`.
Brand-scoped docs take precedence over files in this folder.
