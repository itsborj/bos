# Google Business Profile — Client Onboarding Workflow

**Type:** Operational Checklist  
**Activation:** CMO command or manual start from Admin Workspace  
**What it produces:** A live task list the operator works through step by step. No LLM execution per item.

---

## How to use

Select a section to activate its sub-checklist. Each sub-item becomes a trackable task. Check off items as you complete them. Required fields are marked `[req]`.

---

## 1. Access & Account Setup

- [ ] Obtain client GBP access email `[req]`
- [ ] Send Google Business Profile access invitation
- [ ] Confirm client has accepted access
- [ ] Verify profile is claimed and verified
- [ ] Confirm correct business category is set
- [ ] Add/update business hours
- [ ] Add/update business description (750 char max)
- [ ] Add service area if applicable

## 2. Discovery & Questionnaire

- [ ] Send onboarding questionnaire link to client `[req]`
- [ ] Receive completed questionnaire
- [ ] Extract: brand voice, key services, target area, photos available
- [ ] Log discovery notes in Brand workspace

## 3. Creative Assets

- [ ] Request: logo (PNG, transparent background)
- [ ] Request: cover/header photo
- [ ] Request: product/service photos (min 3)
- [ ] Request: team photos (optional)
- [ ] Request: promotional video (optional, max 30s)
- [ ] Confirm assets received and uploaded to GBP

## 4. Content Foundation

- [ ] Upload all received photos to GBP
- [ ] Write and publish initial GBP posts (first 3)
- [ ] Add products/services to profile
- [ ] Set up Q&A section with 5 common questions
- [ ] Confirm website link is correct
- [ ] Add phone number and confirm call tracking if used

## 5. Kickoff Call

- [ ] Schedule kickoff call `[req]`
- [ ] Send kickoff call invite with agenda
- [ ] Conduct kickoff call
- [ ] Share action items from kickoff
- [ ] Confirm team contacts introduced `[req]`

## 6. Handoff

- [ ] Share Google Drive onboarding folder with client `[req]`
- [ ] Send kickoff/welcome email summary
- [ ] Confirm client knows how to submit review requests
- [ ] Set first 30-day check-in reminder
- [ ] Mark onboarding complete in workspace
